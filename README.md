# Проект Django_project 
## Описание:
В данной работе создан проект интернет-магазина на Django. 
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/Django_project
```
3. Установите зависимости через Poetry:
```
poetri install
```
4. Активируйте виртуальное окружение:
```
poetry shell
```
5. Запустите сервер:
```
python manage.py runserver
```
6. Создайте файл .env из копии файла .env.example и замените значения переменных реальными данными
7. Создано приложение под названием catalog.
8. Реализованы страницы:
- главная
- контакты.
9. На странице с контактными данными пользователи могут заполнить форму и после отправки они получают сообщение об
успешной отправке данных
