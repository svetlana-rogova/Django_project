# Проект Django_project 
## Описание:
В данной работе создан проект интернет-магазина и блога на Django. 
## Установка и использование:
1. Откройте PyCharm
2. Клонируйте репозиторий:
```
git clone https://github.com/svetlana-rogova/Django_project
```
3. Установите зависимости через Poetry:
```
poetri install
```
4. Активируйте виртуальное окружение:
```
poetry shell
```
5. Запустите сервер:
```
python manage.py runserver
```
6. Создайте файл .env из копии файла .env.example и замените значения переменных реальными данными
7. Созданы веб-приложения под названием catalog и blogs
8. Реализованы страницы в catalog:
- главная
- контакты
- информация о продукте
9. Реализованы страницы в blogs:
- главная с возможностью добавления статей
- список статей
- страница для удаления статей
9. На странице с контактными данными в приложении catalog пользователи могут заполнить форму и после отправки они 
получают сообщение об успешной отправке данных. Также пользователь может добавить товар в каталог приложения.
10. На странице с товарами в приложении catalog реализована пагинация
11. В приложении blogs реализована функция отправки сообщения на указанные адрес электронной почты. Для настройки
данного параметра необходимо заполнить данные в .env, а список получателей можно изменить в переменной recipient_list
в методе класса BlogDetailView
12. Реализована функция добавления новых статей в приложении blogs с демонстрацией только тех статей, у которых указан 
флаг публикации
